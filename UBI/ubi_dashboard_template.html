UBI 상권 기후 대응 대시보드

시연용 · 2025-07~12 실제 예보·관측으로 재현한 화면 · 카드 매출 기준
시연용 화면입니다. 2025년 7~12월 전체 자료로 적합한 모형을 같은 기간 예보에 적용한 값이라 실제 예측 성능이 아닙니다. 실제 서비스에는 여러 해의 카드 매출을 쌓아 모형을 안정화하고 매년 갱신해야 하며, 결과는 "가능성"으로 표현해야 합니다. 예측 성능은 아래 "사전 규칙으로 고른 사례일"에서 해당 주를 제외하고 적합한 값으로 확인합니다.

일별 예상 피해 (대상 업종 합계)

이날 업종별 예상 피해

알림 등급별 과거 성적

해당 주를 제외하고 적합한 예측 vs 관측 강수 기준 모형 추정(8/26 이후, 공휴일 주 제외). 실제 매출로 검증한 값이 아님

사전 규칙으로 고른 사례일

유형별 예보 강수량 중앙값인 날(8/26 이후, 공휴일 주 제외). 해당 주를 제외하고 적합한 계수 사용. 구간은 계수 불확실성만 반영하며 예보 오차는 빠져 있어 실제 신뢰구간보다 좁습니다.

집단별 지원 방안 (선택한 날 기준)

금액 기준·취약도 기준 각각 상위 5개 업종으로 집단을 나눕니다.
시군구 전체 평균이며, 개별 점포 예측이 아닙니다.

강수량별 하루 매출 감소율

비슷했던 날 (관측 강수량 10mm 이상, 모델 추정 피해)

• 예상 피해 = 비가 없었을 때의 기준 매출 − 예보 강수량에서 예상되는 매출. 기준 매출은 직전 4주 같은 요일 실제 매출을 모형 효과로 보정해 평균한 값, 강수 계수는 예보 입력으로 적합한 값입니다. • 알림 단계는 이 프로젝트의 2025-07~12 자료에서 정한 기준(예보 1mm, 10mm, 강수확률 60%)이며 기상청 특보 기준이 아닙니다. 강수확률만 높은 날은 모형상 예상 피해가 0입니다. • 우선순위·감소율은 AWS 관측으로 추정한 계수 기준입니다(규모 축 = 하루 피해액×확신도 순위와 보수 score 순위의 평균, 상대 축 = 매출 대비 총 피해 순위). 구간은 95% 구간입니다. • 카드 매출 기준이며 전체 시장 매출이나 이익이 아닙니다. 한 계절 자료이고, 회복(이연 소비) 효과는 반영하지 않았습니다. • 집단 구분: 규모 축과 상대 축 각각 상위 5개. 종합은 두 축 값의 평균입니다. • 지원 방안은 제안이며 효과는 검증하지 않았습니다. 지원 후 비슷한 강수일과 비교하는 사후 평가가 필요합니다.
